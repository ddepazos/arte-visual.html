# Recursos de Arte Visual

Esta carpeta está destinada a videos e imágenes de las obras del portafolio.

Los videos deben subirse como archivos binarios reales (por ejemplo, `.mp4` o `.webm`) y referenciarse desde `index.html` con rutas como `assets/nombre-video.mp4`.

No se incluyen videos en este commit: el conector de GitHub disponible admite crear archivos de texto, pero no transferir archivos de video binarios.
